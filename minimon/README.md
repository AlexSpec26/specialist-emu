# Минимальный монитор «Специалиста» — пишем с нуля

Учебный проект владельца (2026-10-26): «давай начнем писать самый минимальный монитор. начнем с
нуля». Каждый шаг — отдельный исходник, собирается в маленькое ПЗУ, которое можно поставить в
эмулятор (меню → «Сменить ПЗУ»). Справка по командам — `docs/i8080-tutorial.html`.

Сборка шага:

    python3 ../shell/tools/asm80.py step1.asm -o step1.rom --base C000 --size 800 -l step1.lst

| Шаг | Что делает |
|---|---|
| step1 | сброс → переход в ПЗУ, стек, настройка ВВ55, очистка экрана, рамка — «жив» |
