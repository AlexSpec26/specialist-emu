# Эмулятор ПК «Специалист» для Android

Нативное Android-приложение, эмулирующее советский компьютер «Специалист»
(КР580ВМ80А на 2 МГц, экран 384×256, клавиатура через КР580ВВ55).

## Установка

1. Откройте на телефоне страницу **Releases** этого репозитория
   (`github.com/AlexSpec26/specialist-emu/releases/latest`).
2. Скачайте файл `specialist-N.apk` и откройте его. Если Android спросит,
   разрешите установку из этого источника (браузера или «Моих файлов»).
3. Новые версии ставятся поверх старой: настройки, программы и раскладки кнопок сохраняются.

## Первый запуск

1. Приложение попросит файл ПЗУ монитора (например `spec_m2.rom`, 2–12 КБ).
   Если ПЗУ разбито на несколько файлов, выберите их все сразу:
   они склеятся по алфавитному порядку имён.
2. На запрос `PROGRAM ?` нажмите любую из клавиш **F1–F11**, затем **ВК**,
   и откроется Монитор.
3. Игры загружаются через меню ☰ → «Загрузить программу (.rks)».
   Программа сразу запускается и попадает в «Мои программы».

## Управление

- **Джойстик** слева и **1–4 кнопки** справа. Переназначаются через меню ☰ →
  «Настроить кнопки»: выберите элемент и нажмите нужную клавишу на экранной клавиатуре.
  Раскладка запоминается отдельно для каждой программы; кнопкой «Сделать общими»
  её можно назначить раскладкой по умолчанию.
- **⌨** показывает полную клавиатуру «Специалиста». **НР** (Shift) действует на
  следующую нажатую клавишу, **Р/Л** переключает латиницу и кириллицу.
- Поддерживаются Bluetooth-клавиатура и геймпад (крестовина и A/B/X/Y идут на джойстик и кнопки).
- Меню: быстрое сохранение и загрузка, турбо ×5, сброс, цвет экрана
  (белый, зелёный, янтарный, цветной 8 цветов), звук, вибрация.
- Состояние машины сохраняется автоматически при выходе из приложения.

## Устройство проекта

- `app/src/main/java/com/alexspec/specialist/core/`: ядро (процессор 8080, машина, клавиатура).
  От Android не зависит.
- `app/src/main/java/com/alexspec/specialist/`: приложение (экран, джойстик, клавиатура, меню).
- `tools/`: настольные тесты ядра. `CpuTest` прогоняет классические диагностики 8080
  (TST8080, 8080PRE, CPUTEST, 8080EXM, все проходят), `MachineTest` загружает ПЗУ
  и игры и делает скриншоты.
- Каждый push в `main` собирает APK на GitHub Actions и публикует его в Releases.
