# Эмулятор Atari 65XE для Android

Отдельное приложение `com.alexspec.atari` («Atari 65XE»). Эмулирует Atari 800XL / 65XE:
PAL, 64 КБ, процессор 6502, видео ANTIC/GTIA, звук POKEY. Игровое ядро — готовый
эмулятор Atari800 (через интерфейс libretro), а не своё, как в «Специалисте» и ZX (почему —
ADR-021-ATARI в `DECISIONS.md`).

## Установка
Releases → тег `atari-build-N` → файл `atari-65xe-N.apk`. Обновление ставится поверх,
программы и сохранения остаются. Нужен 64-битный телефон (arm64), Android 7 или новее.

## Первый запуск
1. Открывается Atari BASIC (свободная замена Altirra BASIC, свои ПЗУ не нужны).
   Кнопка ⌨ — клавиатура; наберите `PRINT 123` и RETURN.
2. ☰ → «Поймай звезду» — маленькая демо-игра, написанная для этого приложения:
   ведите букву A джойстиком к звёздочкам, FIRE — звук.
3. Свои игры: ☰ → «Открыть программу / диск / картридж». Файл копируется в библиотеку
   приложения («Мои программы»), оригинал не меняется. Многим играм после загрузки
   нужно нажать START.

## Управление
- Экранные: джойстик и FIRE; строка START, SELECT, OPTION, ESC, RETURN; по ⌨ вместо
  джойстика — клавиатура (SHIFT и CTRL залипают до следующей клавиши). Мультитач.
- Физическая клавиатура: буквы, цифры, Enter, Backspace, Esc, Tab, Shift, Ctrl;
  стрелки — джойстик; F1/F2/F3 — START/SELECT/OPTION.
- Геймпад: крестовина или стик — джойстик, A/B — FIRE.

## Меню
| Пункт | Что делает |
| --- | --- |
| Открыть программу / диск / картридж | XEX/COM/EXE, ATR, CAR, CAS (а также XFD, ATX, DCM) |
| Мои программы | ранее открытые файлы |
| Поймай звезду, Atari BASIC | встроенная игра; чистый BASIC |
| Сохранить / Загрузить состояние | один быстрый снимок на программу |
| Сброс Atari | холодный старт текущей программы |
| Память | 64 КБ работающей машины страницами по 256 байт (hex) |
| Настройки | звук; BASIC при загрузке игр (по умолчанию выключен — так нужно большинству игр); свои OS (16 КБ) и BASIC (8 КБ); возврат к свободным Altirra |
| О программе и лицензии | авторы, лицензии всех частей |

При сворачивании и смене программы состояние сохраняется автоматически и восстанавливается,
когда программа открывается снова. Снимок привязан к файлу программы, ПЗУ и настройке BASIC.
Игры могут писать в свою копию ATR-диска; снимок состояния эти записи не откатывает.

## Чего нет и что не проверено
- На телефоне владельцем не проверялось (агенты проверяют только на ПК).
- Нет инструментов, как в ZX/SPEC: карты памяти со вспышками, пошагового исполнения,
  замедления, назначения кнопок на каждую игру. Это следующие задачи (`BACKLOG.md`, ATARI-004…).
- Совместимость со всеми играми не заявляется: с Altirra OS работает не всё (тогда помогает
  своё оригинальное ПЗУ), некоторым играм нужны NTSC, 128 КБ или особые устройства.
- Защищённые ATX и настоящие CAS отдельно не проверялись. 32-битные телефоны не поддерживаются.

## Как устроено
```
atari/
  src/main/java/com/alexspec/atari/
    AtariActivity   экран, меню, импорт файлов, настройки, физические клавиши/геймпад
    PlayView        картинка Atari + экранные джойстик, консольные клавиши, клавиатура
    AtariRunner     поток эмуляции: кадры ~49,86 Гц, звук 44,1 кГц, снимки состояния
    NativeAtari     вызовы нативного ядра (все — из потока эмуляции)
  src/main/jni/
    native/engine.c минимальный libretro-фронтенд: настройки машины, видео, звук, ввод
    native/jni.c    мост Java ↔ engine.c
    vendor/atari800 исходники Atari800/libretro (зафиксированная версия, правки — THIRD_PARTY.md)
    Android.mk      сборка libatari_engine.so (NDK); Makefile.host — сборка тестов на ПК
  src/main/assets/  demos/catch-the-star.xex, licenses.txt (оба генерируются, см. ниже)
  tools/            make_demo.py (демо-игра), make_notices.py (licenses.txt),
                    package_source.py (архив исходников для релиза)
```
Приватные файлы приложения: `games/` — библиотека (имя файла — SHA-256 содержимого),
`states/` — снимки, `ATARIXL.ROM` / `ATARIBAS.ROM` — свои ПЗУ (если установлены).

## Проверка и сборка
Тесты запускают настоящее ядро на ПК с Altirra OS/BASIC (нужны gcc, make, zlib, JDK 17):
```sh
python3 atari/tools/make_demo.py
make -s -f atari/src/main/jni/Makefile.host test DEMO="$PWD/atari/src/main/assets/demos/catch-the-star.xex"
JAVA_HOME=/path/to/jdk make -s -f atari/src/main/jni/Makefile.host jni-test DEMO="$PWD/atari/src/main/assets/demos/catch-the-star.xex"
```
`tools/AtariNativeTest.c` проверяет: загрузку BASIC и ввод `PRINT 123`; XEX-игру, джойстик,
звук POKEY и картинку; сохранение/восстановление (память совпадает после повтора); загрузку
с ATR-диска; картридж CAR; повторные запуски и неверный файл. В CI — ещё и под AddressSanitizer.
`tools/AtariJniTest.java` — тот же мост JNI, что в APK, на настольной JVM.

APK: `gradle :atari:assembleDebug` (Android SDK 35, NDK 27.2.12479018 — Gradle ставит его сам).
CI — `.github/workflows/atari.yml`: на PR только проверки, на `main` — подписанный релиз
`atari-build-N` с архивом исходников `atari-source-N.tar.gz`. Ключ подписи только в секретах
(ADR-014). Сборка Atari не запускает сборки других продуктов и наоборот (ADR-013).

## Лицензии
Модуль `atari/` распространяется под GPL-2.0-or-later (из-за ядра Atari800); остальные
продукты репозитория это не затрагивает. Полный текст — `COPYING`, происхождение и правки —
`THIRD_PARTY.md`, все уведомления — в приложении («О программе и лицензии»). Встроенные
Altirra OS/BASIC (© Avery Lee) свободно распространяемы; оригинальные ПЗУ Atari и чужие
игры в APK не входят. «Поймай звезду» и её генератор — CC0.
Если меняете `THIRD_PARTY.md`, `COPYING` или файлы ядра — запустите
`python3 atari/tools/make_notices.py` (CI проверяет, что `licenses.txt` актуален).
