# Эмулятор Atari 65XE для Android

Отдельное приложение `com.alexspec.atari` («Atari 65XE»). Эмулирует Atari 800XL / 65XE:
PAL, 64 КБ, процессор 6502, видео ANTIC/GTIA, звук POKEY. Устроено и выглядит так же, как
эмулятор ZX Spectrum из этого репозитория: тот же экран, меню, карта памяти, скорость, шаги.
Игровое ядро — готовый эмулятор Atari800 (ADR-021-ATARI), а время внутри кадра, шаги назад
и карта памяти — наши дополнения к нему (ADR-023).

## Установка
Releases → тег `atari-build-N` → файл `atari-65xe-N.apk`. Обновление ставится поверх.
Нужен 64-битный телефон (arm64), Android 7 или новее.

## Что умеет (как в ZX)
- Экран 4:3, тап по экрану — пауза. В паузе внизу экрана: ⏪ 1 с, ◀ 1 команда, 1 ▶, 1 с ⏩;
  4 секунды видны луч (красное перекрестие) и команда 6502 с регистрами A X Y S P и флагами.
  Назад — до 10 секунд; вперёд после этого повторяется то, что было, пока игра не продолжена.
- Скорость: ползунок от ×4 до 1 такта в секунду, каждый шаг — вдвое; видно, как луч рисует кадр.
- Визуализация памяти: карта всех 64 КБ под экраном (портрет), 1–4 байта в строке, вспышки
  чтения (зелёный), записи (малиновый), обоих (жёлтый), исполнения (голубой); щипок, перетаскивание,
  двойной тап; тап по байту — адрес, значение и что это (переменные ОС и BASIC, список
  отображения ANTIC, экран, шрифт, регистры микросхем, входы ПЗУ). Экскурсия по памяти Atari из
  13 шагов. Отмечаются обращения процессора; чтение экрана и шрифта видеочипом ANTIC не видно.
- Джойстик и 1–4 кнопки; на каждую — джойстик, FIRE или любая клавиша; раскладка своя для
  каждой программы, готовые раскладки (в т. ч. стрелки Atari = CTRL + − = + *).
- Клавиатура 800XL (кнопка ⌨): SHIFT и CTRL залипают на одну клавишу, красным — символ с SHIFT,
  синим — с CTRL; верхний ряд — HELP, START, SELECT, OPTION, пробел, RESET, BREAK.
- Программы: XEX/COM/EXE, ATR/XFD/ATX/DCM, CAR, ROM/BIN (картриджи без заголовка — тип по
  базе ядра или размеру), CAS («Открыть файл» → «Мои программы»). Картридж приставки 5200 (.a52,
  или .rom/.bin из базы 5200) запускает 5200 со свободной Altirra 5200 OS: START/SELECT/OPTION —
  её START/PAUSE/RESET, цифры — её клавиатура, второй огонь — SHIFT. Игры Atari 2600 — другая
  машина, приложение их распознаёт и не запускает;
  встроенная демо-игра «Поймай звезду»; Atari BASIC отдельным пунктом.
- Сохранения у каждой программы, экспорт/импорт, автосохранение при сворачивании.
- «ПЗУ и BASIC»: встроены свободные Altirra OS и BASIC; можно поставить свои оригинальные
  (16 КБ ОС, 8 КБ BASIC); BASIC при запуске программ включается отдельно (по умолчанию выкл).
- Физическая клавиатура и геймпад: буквы, цифры, знаки, Enter, Backspace, Esc, Tab, Shift, Ctrl;
  F1/F2/F3/F4 — START/SELECT/OPTION/HELP; крестовина — джойстик, A/B/X/Y — кнопки 1–4.

Файлы: `Android/data/com.alexspec.atari/files/programs` и `.../states` (видны по USB).
Библиотека из сборок до atari-build-10 переносится в `programs` при первом запуске.

## Чего нет и что не проверено
- На телефоне владельцем не проверялось (агенты проверяют только на ПК).
- Магнитофона через микрофон, как в ZX/SPEC, нет (файлы .cas открываются как кассеты).
- В медленном режиме и при шагах звук — по целым кадрам (кадр звучит, когда закончится).
- Совместимость со всеми играми не заявляется: с Altirra OS идёт не всё (помогает своё ПЗУ),
  некоторым играм нужны NTSC или 128 КБ. 32-битные телефоны не поддерживаются.

## Как устроено
```
atari/src/main/java/com/alexspec/atari/
  EmuActivity, MainView, MapPanel, EmuThread, ControlConfig, Speed   — перенесены из ZX
  AtariKeys (клавиши 800XL), Games (встроенная демо), Tutorial (экскурсия по памяти Atari)
  core/AtariMachine  машина для экранов: тот же вид, что Spectrum48 в ZX (run, шаги, луч, клавиши)
  core/NativeAtari   вызовы ядра; core/MemTrace (из ZX); core/Dis6502 (дизассемблер строки)
atari/src/main/jni/
  native/engine.c    libretro-фронтенд: машина 800XL/PAL, клавиши кодами Atari, картинка, снимки
  native/timeline.c  время: остановка между командами, шаги, история 10 с, карта обращений
  native/alexspec_hooks.h  хуки, вкомпилированные в cpu.c ядра (-DALEXSPEC_HOOKS)
  native/jni.c       мост Java ↔ engine
  vendor/atari800    ядро Atari800/libretro (зафиксированная версия; правки — THIRD_PARTY.md)
  Android.mk, Makefile.host (сборка тестов на ПК)
atari/tools/  make_demo.py (демо-игра), make_notices.py (licenses.txt), package_source.py
```
Как остановиться посреди кадра: ядро умеет только целые кадры. Хук перед каждой командой
(в `cpu.c`) при достижении нужной точки выходит из ядра через `longjmp`; машину в таком
состоянии не продолжают — восстанавливают снимок начала кадра и прогоняют кадр заново до
следующей точки (эмуляция детерминирована, повтор идентичен). Назад — так же, от снимков,
сохранённых каждые 10 кадров за 10 с, с записанными органами управления каждого кадра.

## Проверка и сборка
Тесты запускают настоящее ядро на ПК с Altirra OS/BASIC (нужны gcc, make, zlib, JDK 17):
```sh
python3 atari/tools/make_demo.py
make -s -f atari/src/main/jni/Makefile.host test DEMO="$PWD/atari/src/main/assets/demos/catch-the-star.xex"
JAVA_HOME=/path/to/jdk make -s -f atari/src/main/jni/Makefile.host jni-test DEMO="$PWD/atari/src/main/assets/demos/catch-the-star.xex"
```
`tools/AtariNativeTest.c`: загрузка BASIC и ввод `PRINT 123`; игра, джойстик, звук, картинка;
**замедление = обычный ход** (те же кадры кусками со случайными остановками внутри кадров — больше
1000 остановок — дают ту же память и регистры, отдельно для джойстика и для клавиатуры); шаги на
команду вперёд и назад, секунда назад и вперёд, отметки карты, глубина истории; сохранение
посреди кадра; ATR, CAR, голый ROM (и сброс), картридж 5200 (джойстик, клавиатура, шаги),
неверный файл. В CI — ещё и под AddressSanitizer.
`tools/AtariJniTest.java`: тот же мост JNI, что в APK, и слой `AtariMachine` (короткое касание
клавиши доходит до машины ровно один раз, шаги, карта) — на настольной JVM.

APK: `gradle :atari:assembleDebug` (Android SDK 35, NDK 27.2.12479018 — Gradle ставит его сам).
CI — `.github/workflows/atari.yml`: на PR только проверки, на `main` — подписанный релиз
`atari-build-N` с архивом исходников `atari-source-N.tar.gz`. Ключ подписи только в секретах
(ADR-014). Сборка Atari не запускает сборки других продуктов и наоборот (ADR-013).
