# Оболочка в ПЗУ «Специалиста»

Своё ПЗУ на место Монитора-2: текстовая оболочка 64×32 с псевдографикой, строчными
буквами и переключением между программами.

- `C000–C7FF` — базовое ПЗУ «Специалиста», байт в байт (игры вызывают его подпрограммы
  напрямую, читают шрифт и даже байты кода).
- `C800–C836` — точки входа как у Монитора-2; подпрограммы `CE1D`, `CE5C`, `CE9D`, `CEC8`
  стоят на тех же адресах, что в Мониторе-2.
- `C836–EFFF` — оболочка.

Сборка: `cd shell/src && python3 ../tools/asm80.py main.asm -o ../build/shell.rom --base C000 --size 3000`

Запуск: после включения «PROGRAM ?» — F1, затем ВК.

Инструменты: `tools/asm80.py` — ассемблер 8080, `tools/dis80.py` — дизассемблер,
`tools/mkfont.py`, `tools/mkkeys.py` — генераторы шрифта и таблиц клавиатуры.
