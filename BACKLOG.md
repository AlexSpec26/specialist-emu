# Бэклог

Префиксы: `SPEC` — эмулятор «Специалиста», `ROM` — оболочка/программы для «Специалиста»,
`ZX` — эмулятор Спектрума, `FLIP` — флиппер, `OPS` — репозиторий и сборки.
Крупные задачи — полным шаблоном из `AGENTS.md`, мелкие — одной строкой.
«Устройство: не проверено» значит, что агент проверил только на ПК/компиляцией.

### ROM-001 — Быстрый вывод текста
- Status: Done (2026-10-25), устройство: не проверено (замер в ядре эмулятора, 2 МГц)
- Why: полная перерисовка плотного экрана ~0,9 с, простого ~0,4 с — для «Памяти» медленно.
- Done: 4 символа с колонки, кратной 4, пишутся целиком в 3 байта экрана (GRP4) — PUTS и REPCH
  используют это сами; прокрутка SCROLLUP/SCROLLDN сдвигом экранной памяти через стек.
  Экран после перерисовки байт в байт тот же, что был (проверено).
- Результат (было → стало): строка 64 символа 44 → 24 мс; «Обзор» 955 → 595 мс; заглушка

- Не достигнуто: «Обзор» ≤ 0,35 с и строка в «Памяти» ≤ 0,1 с (цели ставил агент). Предел без
  больших таблиц ~80 тактов на байт экрана; дальше — только сдвинутые копии шрифта (+2…4 КБ ПЗУ),
  не стоит того. Правило для программ: строку собирать в буфере ОЗУ и печатать PUTS одним
  куском с колонки, кратной 4; PUTCH/PHEX8 по одному символу — вдвое медленнее.
- Validation: `tools/ShellTiming.java` (в CI ROM, порог «Обзора» 650 мс, проверка прокрутки

### ROM-006 — «Магнитофон»
- Status: Done (2026-10-25), устройство: не проверено (лента эмулятора)
- Done: F2 чтение блока (формат Монитора-2: 255×00, E6, начало, конец, байты, сумма) с
  полоской прогресса; выше 8DFF не пишется (там оболочка) — «обрезано»; проверка суммы.
  F3 запись диапазона (единственное место записи, ADR-005). F5 запуск загруженного; его RET
  возвращает в оболочку. Тёплый старт C800 (выход игры, остановка чтения клавишей) теперь
  сохраняет запущенные программы и их состояние (подпись A55A в 8F0A).
- Файлы с именем как у Монитора-2 (2026-10-25): F2 узнаёт заголовок D9 D9 D9 + имя (команда O)
  и показывает «имя файла»; F3 спрашивает имя (ВК — без имени) и пишет как O: заголовок,
  потом блок. Имя — заглавными (латиница 41–5A, русские 60–7F), до 15 знаков.
- Validation: `tools/ShellTapeTest.java` (в CI): + именованный файл оболочки читает I
  Монитора-2 (C9CB), файл формата O Монитора-2 (CAB0) читает оболочка; запись→чтение через ленту эмулятора; запись
  Монитора-2 (C827) читается оболочкой; запись оболочки читается Монитором-2 (C824); F5 и
  возврат.
